#DOS_Lab2_DL

## Reto #2 – El chef de 5 estrellas

Patrón de Diseño
Creacional --> builder

Justificación:
El patrón Builder permite construir objetos complejos paso a paso,
ideal cuando un producto tiene múltiples partes opcionales como una hamburguesa.

Cómo lo aplico:
- Hamburger es el producto final
- HamburgerBuilder construye la hamburguesa paso a paso
- Chef actúa como lider
- usamos streams para calcular el precio total
